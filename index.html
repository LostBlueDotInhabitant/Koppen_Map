File format and how to export from Python

Each file holds 64,800 values (a JSON list, or numbers/labels separated by commas or newlines), in the same order as reshape_predictions_to_grid expects: row-major, rows from south to north, columns from longitude −180 to 180. Empty, null or NaN values are drawn as blank. Köppen labels such as “Cfb” get the standard Köppen colours; any other labels get generated colours.

import json
json.dump(koppen_flat.tolist(), open("koppen.json", "w"))                       # tree.predict(...), shape (64800,)
json.dump(temp_flat.astype(float).round(2).tolist(), open("temperature.json", "w"))  # regression .predict(...)
